# Tarea 09 - Maquetación Web

Práctica de maquetación web desarrollada con Bootstrap 5, cumpliendo con los requerimientos de estructura y diseño responsivo.

## ¿Qué incluye este proyecto?
* **Navbar superior:** Barra de navegación principal en la parte superior con título e icono.
* **Tabla de productos:** Listado con datos de ejemplo (ID, nombre, precio, stock) y sus respectivos botones de acción (Editar y Eliminar).
* **Modal de registro:** Formulario flotante para registrar nuevos productos que se abre directamente desde la interfaz.

## Tecnologías usadas
* HTML5
* Bootstrap 5 (v5.3.3)
* Bootstrap Icons
